# 🚀 Personal Portfolio — Supriti Basak

🔗 **Live Demo:** [https://portfolio-sb-beta.vercel.app/](https://portfolio-sb-beta.vercel.app/)

---

## ✨ Overview

A modern, interactive developer portfolio built to showcase my projects, skills, and experience through a visually engaging interface. The application combines **3D elements, smooth animations, and a clean UI** to deliver an immersive and responsive user experience.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite
* **Styling:** Tailwind CSS
* **3D & Graphics:** Three.js, @react-three/fiber, drei
* **Animations:** GSAP
* **Email Integration:** EmailJS
* **Deployment:** Vercel

---

## 🔥 Features

* 🎯 Interactive 3D sections and components
* ⚡ Smooth animations using GSAP
* 🧠 Dynamic project showcase
* 🕒 Responsive timeline-based experience section
* 📩 Functional contact form using EmailJS
* 🎨 Modern dark UI with subtle visual effects
* 📱 Fully responsive design

Create a `.env` file and add:

