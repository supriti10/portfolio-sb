🚀 Personal Portfolio Website

A modern, responsive developer portfolio built to showcase my work, skills, and passion for creating impactful digital experiences. Designed with a minimal, dark-themed UI and smooth interactions, the portfolio highlights both my full-stack development and machine learning projects.

✨ Features
Clean and aesthetic dark UI with a premium feel
Interactive hero section with 3D elements (Three.js)
Smooth animations and transitions for better UX
Custom logo branding (SB) with hover effects
Fully responsive across devices
Sections for About, Work, and Contact
🛠️ Tech Stack
Frontend: React.js, Next.js
Styling: Tailwind CSS
3D & Animations: Three.js, @react-three/fiber
Tools: Git, GitHub, Vercel

🎯 Goal

To create a visually appealing and performance-optimized portfolio that not only showcases my projects but also reflects my design sense and development skills.
